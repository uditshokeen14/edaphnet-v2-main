# Data collection templates (step 6)

Open in Excel. Protocol: `docs/15_step6_real_data_protocol.md`.

- `sample_log.csv`: one row per physical sample (field, location, preparation, lab batch)
- `capture_log.csv`: one row per photo
- `lab_results.csv`: lab values, entered **twice** by two people (`entry_round` 1 and 2)
- `duplicate_key.csv`: **keep private; never share with the lab**. It maps blind duplicates to originals
